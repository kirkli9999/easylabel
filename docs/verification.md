## 已完成

- Node.js 24.14.0 / Windows，本機 `npm run check`：型別檢查、35個Vitest案例、正式build通過。
- `npm run test:e2e`：9個Chromium瀏覽器案例通過；測試正式build的`/easylabel/`子路徑，字型與PDF worker無404。

- 實際PDF於PDF.js完成渲染後檢查：繁體中文、數字、營養表、有效日期、雙標籤裁切線與草稿浮水印顯示完整。
